# AQUA STAFF BOT (@aqua18admin_bot)

Персональный Telegram-бот для состава администрации сервера AQUA.

## 📌 Основные возможности
1. **Одна кнопка для администратора:** Нажатие на `[📊 Моя статистика]` сразу выводит карточку с личными данными из Google Таблицы (должность, уровень, дата назначения, дни на посту, баллы, токены, устные/письменные/строгие выговоры, неактивы, иммунитеты).
2. **Мгновенная авторизация:** Telegram ID и юзернеймы большинства администраторов уже сопоставлены с их игровыми никами в таблице. Если админа нет в списке, он один раз вводит свой `Nick_Name` и бот навсегда привязывает его к SQLite базе.
3. **Функции руководства (ЗГА/ГА/Кураторы):**
   - Кнопка `[🔍 Найти админа]` — быстрый просмотр досье любого администратора по его нику.
   - Кнопка `[🔄 Обновить данные]` — принудительный сброс кэша и мгновенная подгрузка свежих данных из таблицы.
4. **Фоновый авто-кэш:** Каждые 5 минут бот в фоновом потоке обновляет данные из Google Таблицы, поэтому ответы на кнопки приходят мгновенно (0.01 сек).

## 🚀 Запуск на Windows (локально)
Просто запустите файл `start_bot.bat`. Он автоматически проверит библиотеки и запустит `bot.py`.

---

## 🐧 Запуск на Linux VPS (сервер 2 vCPU / 1 GB RAM)
Бот потребляет всего ~35-40 МБ оперативной памяти и работает независимо от основного бота.

### 1. Установка зависимостей:
```bash
cd /opt/aqua_staff_bot
python3 -m pip install -r requirements.txt
```

### 2. Запуск через screen:
```bash
screen -S staff_bot python3 bot.py
```
(Чтобы свернуть: нажмите `Ctrl+A`, затем `D`. Чтобы вернуться: `screen -r staff_bot`).

### 3. Запуск как системный сервис (systemd) — автозапуск при перезагрузке:
Создайте файл сервиса `/etc/systemd/system/aqua_staff.service`:
```ini
[Unit]
Description=AQUA Staff Telegram Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/aqua_staff_bot
ExecStart=/usr/bin/python3 bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```
Активируйте и запустите:
```bash
systemctl daemon-reload
systemctl enable aqua_staff
systemctl start aqua_staff
systemctl status aqua_staff
```
